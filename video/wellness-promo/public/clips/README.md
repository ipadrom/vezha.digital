# Generated motion clips

Place three image-to-video exports here:

- `run.mp4`
- `train.mp4`
- `nutrition.mp4`

Requirements: 16:9, 5 seconds or longer, H.264 MP4, no audio, no baked-in text, logos, phones, or app interface.

The `WellnessPromoFinal` composition uses these files. The `WellnessPromoStoryboard` composition continues to use the still images from `public/assets`.
