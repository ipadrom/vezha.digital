## 1. Характер бренда

- **Кто:** VEZHA Digital — компактная продуктовая команда полного цикла. Один ответственный человек ведёт проект от первого разговора до запуска, без субподряда.
- **Обещание:** «Продукты, которые работают в вашем бизнесе».
- **Визуальная формула:** монохромная редакционная типографика, холодная пастельная дымка на фоне и тёмная «жидкая капля». Сквозь каплю видно переливающийся «негатив» заголовка.
- **Ощущение:** дорого, спокойно, технологично без «хакерского» китча. Много воздуха. Движение с мягкой посадкой, ничего не мельтешит.
- **Темы:** светлая — основная (так сайт открывается по умолчанию). Тёмная — вторичная: для технических тем и как мир внутри капли.

### 3.2 Акцент: переливающийся градиент

| Токен | Hex | RGB | ASS |
|---|---|---|---|
| lilac | `#AD9CFF` | 173, 156, 255 | `&H00FF9CAD` |
| cyan | `#51D8FF` | 81, 216, 255 | `&H00FFD851` |
| ice | `#F7F9FF` | 247, 249, 255 | `&H00FFF9F7` |

- **Главный градиент:** `linear-gradient(104deg, #F7F9FF 0%, #AD9CFF 38%, #51D8FF 72%, #FFFFFF 100%)`. Идёт почти горизонтально, слева направо и чуть вниз.
- **Компактный** (иконки, аватары, индикаторы): `linear-gradient(145deg, #AD9CFF, #51D8FF)`.
- **Где можно:** текст внутри капли («негатив»); одно акцентное слово или цифра в кадре; мелкие индикаторы.

- **«Негатив» внутри капли:** плоскость `#121318` с мягким голубым свечением `rgba(92,216,255,0.16)` (центр в точке 44 % / 36 %). Заголовки — градиентом, прочий текст — ice `#F7F9FF`, вторичный — `#D7DEF0`, тихий — `#B9BFD0`, линии — `rgba(247,249,255,0.14)`.
- В тёмной теме капля светлая (`#F2F3F5`), текст внутри — тот же градиент. Его светлая часть почти пропадает, поэтому для видео лучше светлая тема с тёмной каплей.

### 3.3 Атмосфера: фон-дымка

Фон сайта — не плоский цвет, а «туман»: вертикальный холодный градиент и крупные размытые пятна голубого, сиреневого и бирюзового. Пятна крупнее ширины кадра, прозрачность низкая (18–30 %). Готовая версия под 9:16 — в Прил. A (CSS) и Прил. B (`mesh_background`, PIL).

- **Светлая:** база `#FBFCFF → #F2F5FF → #FAF7FF → #EEF7FB`. Пятна: голубое `#6B94FF` справа сверху, сиреневое `#CD88FF` слева, бирюзовое `#43CDEC` справа снизу, индиго `#7E6CFF` слева внизу.

Медленно дрейфуют: ±8 % за 48 с, ease-in-out. В ролике движение почти незаметно — фон «живой», а не анимированный.

### 4.3 Правила набора

- UPPERCASE — только для display- и section-заголовков и моно-лейблов. Субтитры, лиды и текст — в обычном регистре.
- Заголовок: 1–3 слова в строке, не больше ~12 знаков при 120 px. Строки режем по смыслу: `ПРОДУКТЫ, / КОТОРЫЕ / РАБОТАЮТ / В ВАШЕМ / БИЗНЕСЕ`.
- Выключка влево. По центру — только финальная CTA-карта (как блок контактов на сайте).
- Моно-лейбл: `РАЗДЕЛ / 03`, `ОБУЧЕНИЕ / 02`, `VEZHA / DIGITAL-СТУДИЯ`. Разделитель « / » цвета hair, номера с ведущим нулём (`01`, `02 / 04`).
- Стрелки типографские (→ ↓ ↗ ↑), не `>>` и не `->`. ₽ — через неразрывный пробел (`30 000 ₽`). Диапазоны — коротким тире (`1–4 недели`). Кавычки «ёлочки». Буква «ё» обязательна.
- Предлоги и союзы (в, и, с, к, на, а) не оставлять в конце строки.
- Разделителя бегущей строки `✦` (U+2726) нет ни в Onest, ни в JetBrains Mono. Брать из Menlo (`/System/Library/Fonts/Menlo.ttc`) или рисовать вектором — четырёхлучевой звездой.
- PIL не умеет letter-spacing: трекинг ставится посимвольно (`draw_tracked`, Прил. B). Длинные трекнутые заголовки удобнее делать в HyperFrames или Remotion — там работает CSS `letter-spacing`.

### 4.4 Файлы шрифтов

- **Onest:** статические TTF в `~/Library/Fonts/Onest-{Regular,Medium,SemiBold,Bold}.ttf`. Лицензия OFL, источник — Google Fonts:

  ```bash
  css=$(curl -s "https://fonts.googleapis.com/css2?family=Onest:wght@400;500;600;700")
  printf '%s\n' "400 Regular" "500 Medium" "600 SemiBold" "700 Bold" | while read -r w name; do
    url=$(printf '%s\n' "$css" | awk -v w="$w" '/font-weight/ {fw=$2} /src: url/ && fw==w";" {match($0, /https:[^)]*\.ttf/); print substr($0, RSTART, RLENGTH)}')
    curl -sfL "$url" -o "$HOME/Library/Fonts/Onest-$name.ttf"
  done
  ```

  После установки проверь, что в Onest есть →, ₽ и «». Чего нет — бери из JetBrains Mono: там →, ↗, ↓, ₽, «», ё есть.
- **JetBrains Mono** стоит как Nerd Font: `~/Library/Fonts/JetBrainsMonoNLNerdFontMono-{Regular,Medium,SemiBold,Bold}.ttf`. Семейство для libass — `JetBrainsMonoNL Nerd Font Mono`. Кириллица есть.
- **PIL:** `ImageFont.truetype(path, size)`, index 0 (это TTF, не TTC).
- **libass:** `Fontname=Onest` + `Bold=-1` → 700. SemiBold — `Onest SemiBold` с `Bold=0`, Medium — `Onest Medium`.
- **HTML-движки (HyperFrames, Remotion):** та же ссылка, что у сайта:
  `https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600&family=Onest:wght@400;500;600;700;800&display=swap`.
  В Remotion — `@remotion/google-fonts/Onest` и `@remotion/google-fonts/JetBrainsMono` с `subsets: ['cyrillic', 'latin']`. Рабочий пример: `media/gbu-crew-graph-remotion/src/CrewRelationshipGraph.tsx`.

## 5. Графические элементы

Размеры даны в пикселях кадра 1080×1920.

**5.1 Жидкая капля — главный фирменный приём.** Органичная клякса цвета ink (в тёмной теме — `#F2F3F5`). Медленно «дышит» и плавает по заголовку. Всё, что под ней, показано в «негативе» (§3.2): тёмная плоскость и текст градиентом.
- Форма (из `useSectionLiquid.ts`): окружность с 3-й, 5-й и 7-й гармониками колебаний. Амплитуды — 9.5 %, 6 % и 3.6 % радиуса, частоты — 2.2, 1.55 и 0.84 рад/с. На ходу капля вытягивается по направлению движения (до +8.5 %) и сплющивается о границы заголовка. Контур — 42 точки, сглаженные в кривую. Код — `blob_points` в Прил. B.
- Размер: радиус ≈ 10.5 % ширины заголовка, в кадре 150–220 px.
- Движение: инерционное, с плавным торможением, без скачков, не быстрее ~400 px/с. Форма колышется даже в покое.
- Применение: одна капля в кадре. Сценарии — хук-титр, ключевой тезис, финальный вордмарк (капля садится на «A») и переход (§6.5).

## 6. Движение

### 6.1 Принципы

- Быстрый старт и долгая мягкая посадка (ease-out quint/expo). Ничего не пружинит: без overshoot, bounce и elastic.
- Появление — подъём снизу плюс проявление. Заголовки выезжают построчно из маски.
- Одно новое на экране за раз, шаг между элементами 70–120 мс. Иначе глаз не успевает.
- Linear — только для бесконечных циклов: бегущая строка и орбита.
- Уход быстрее появления (≈ 0.5–0.6 от входа), кривая ease-in-out.
- Фон «дышит», но это почти незаметно.

### 6.2 Кривые

| Имя | cubic-bezier | Где | Python (Прил. B) | Remotion | GSAP |
|---|---|---|---|---|---|
| ease-out (основная) | `0.23, 1, 0.32, 1` | входы, строки заголовка, карточки, реакции UI | `EASE_OUT` | `Easing.bezier(0.23, 1, 0.32, 1)` | `power4.out` |
| ease-out-expo | `0.16, 1, 0.3, 1` | подъём крупных блоков, pop чипов | `EASE_OUT_EXPO` | `Easing.bezier(0.16, 1, 0.3, 1)` | `expo.out` |
| ease-in-out | `0.77, 0, 0.175, 1` | переходы, шторки, дрейф фона | `EASE_IN_OUT` | `Easing.bezier(0.77, 0, 0.175, 1)` | `power3.inOut` |
| ease-line | `0.76, 0, 0.24, 1` | прорисовка линий, уход прелоадера | `EASE_LINE` | `Easing.bezier(0.76, 0, 0.24, 1)` | `power3.inOut` |
| linear | — | бегущая строка, орбита | — | — | `none` |

Эти кривые заменяют `ease_out_cubic` и `ease_in_out_cubic` из video-use. Если нужна точность в GSAP — `CustomEase` с теми же числами.

### 6.3 Длительности

| Действие | мс | кадров @30 |
|---|---|---|
| Реакция UI (нажатие) | 160 | 5 |
| Смена состояния | 250 | 7–8 |
| Шторка / смена экрана | 600 | 18 |
| Вход элемента, строка заголовка | 720 | 22 |
| Pop чипа или кнопки | 820 | 25 |
| Прорисовка линии, уход прелоадера | 900 | 27 |
| Подъём крупного блока | 950 | 28–29 |
| Шаг между элементами | 70–120 | 2–4 |
| Дрейф фона, оборот орбиты | 48 000 (цикл) | — |

### 6.4 Хореография

- **Подъём:** y +60 → 0, opacity 0 → 1 (opacity чуть короче, 600 мс).
- **Строки заголовка:** каждая строка в своей маске, y 110 % → 0, шаг 70 мс, но не больше 210 мс на весь заголовок.
- **Pop (чипы, кнопки):** y +45 → 0, scale 0.96 → 1, ease-out-expo, шаг 80 мс.
- **Карточка:** x +45 и y +30 → 0, scale 0.97 → 1. **Список:** x −45 → 0. **Мокап:** y +60 → 0, scale 0.96 → 1.
- **Линия:** scaleX 0 → 1 от левого края. Вертикальный коннектор — scaleY снизу вверх, с задержкой 420 мс.
- **Порядок в сцене** (как в hero): лейбл → заголовок (+80 мс) → текст (+260…340 мс) → чипы и кнопки (+350…500 мс) → бегущая строка (+620 мс).
- **Счётчики:** 00 → N по `EASE_OUT`, с ведущими нулями, моноширинно.
- **Уход:** opacity → 0 и y −24 за 300–400 мс, ease-in-out. Или вся сцена уходит шторкой (§6.5).
- **Синхрон с речью:** посадка анимации совпадает со словом-смыслом. Старт = таймкод слова минус длительность входа.

### 6.5 Переходы

- **По умолчанию — прямая склейка:** говорящая голова, скринкасты.
- **«Капля» (фирменный):** капля входит из-за края или растёт из точки, пока не перекроет кадр (r → ≥ 2200 px). Длительность 600–800 мс, ease-in-out. Внутри уже следующая сцена, часто «негатив». Не чаще двух раз за ролик: интро → контент, контент → финал.
- **«Шторка кейса»:** новый кадр въезжает на 100 % ширины, а его содержимое движется навстречу на 95 % (параллакс). 600 мс, ease-out.
- **«Подъём панели»:** сцена целиком уезжает вверх, как прелоадер. 900 мс, ease-line.
- **Нельзя:** растворения между кусками речи, zoom-blur, глитч, 3D-вращения, шаблонные «свайпы» и «вспышки».

Субтитры и так остаются последним слоем. Лишняя перекодировка при CRF 17 визуально незаметна. Для фильтра `ass` нужен ffmpeg с libass (§14).

## 10. Структуры роликов

- **Обучающий (30–60 с):** ХУК — вопрос или обещание (0–2 с) → КОНТЕКСТ, зачем это (до 8 с) → ШАГИ `01…0N` (главы §9.2, списки §9.4, мокапы §9.6) → НЮАНС или частая ошибка → ИТОГ (тезис в «негативе», §9.7) → CTA «Сохраните — пригодится» и финальная карта.
- **Промо студии (15–30 с):** ХУК — боль клиента → ЧТО ДЕЛАЕМ (бегущая строка услуг или чипы) → КАК (этапы: Бриф → Дизайн → UX/UI → Разработка → Тестирование → Запуск → Поддержка) → ДОКАЗАТЕЛЬСТВО (кейс, цифры §9.5) → CTA «Обсудить проект →».
- **Кейс (20–45 с):** РЕЗУЛЬТАТ как хук → ЗАДАЧА → РЕШЕНИЕ (мокап, скринкаст) → ЦИФРЫ → CTA «Кейс целиком — на vezha.digital».

## 11. Грейд живого видео

- **Цель:** чисто, нейтрально-холодно, мягкий контраст, естественная кожа. Белые чуть холодные, тени не «заваливать».
- **Стартовая цепочка `vezha_clean`** (проверена в ffmpeg 8.1). Серый 128 → (123, 127, 126), кожа (200, 150, 120) → (189, 149, 121):

  ```text
  eq=contrast=1.04:saturation=0.92,colortemperature=temperature=7200:mix=0.3:pl=1,curves=master='0/0.02 0.5/0.5 1/0.98'
  ```

  Применение: `grade.py <in> -o <out> --filter "<цепочка>"`. Всегда сверяй тон кожи на кадре (`timeline_view`).
- **Не использовать:** `warm_cinematic` (тёплый teal/orange — не наш), сильную виньетку, «киношные» LUT. Допустим `neutral_punch`.
- **Съёмка:** светлый нейтральный фон (белая или светло-серая стена, холодный градиент), мягкий рассеянный свет, без тёплых жёлтых ламп. Одежда однотонная, лучше тёмно-графитовая или белая.
- **HDR-исходники** (iPhone: HLG, Dolby Vision) переводятся в SDR до грейда. `render.py` делает это через `zscale` — нужен ffmpeg с libzimg (§14).

## 12. Звук

Звука на сайте нет, поэтому это рекомендация под стиль.

- **Музыка:** минималистичная электроника или эмбиент, 90–110 BPM, без вокала, мягкие синты. Под голосом приглушать примерно на 18–22 дБ относительно речи.
- **Эффекты:** тихий «клик» на pop чипов, мягкий воздушный «вжух» на переход-каплю, еле слышное тиканье счётчика. Без кассовых аппаратов, свистов и мемных звуков.
- **Громкость:** итог −14 LUFS (`render.py`).

## 13. Голос и тексты на экране

## Приложение B. Python-хелперы для PIL-анимаций

Проверены в venv video-use: Pillow с FreeType 2.14, numpy. Копируй в скрипт слота целиком, не импортируй между слотами.

```python
import math

import numpy as np
from PIL import Image, ImageDraw

W, H = 1080, 1920
IRIDESCENT = [(0.0, "#F7F9FF"), (0.38, "#AD9CFF"), (0.72, "#51D8FF"), (1.0, "#FFFFFF")]


def hex_rgb(h):
    h = h.lstrip("#")
    return tuple(int(h[i:i + 2], 16) for i in (0, 2, 4))


def cubic_bezier(x1, y1, x2, y2):
    """CSS cubic-bezier(x1, y1, x2, y2) -> f(t), t in [0, 1]."""
    def bez(a1, a2, s):
        return 3 * a1 * s * (1 - s) ** 2 + 3 * a2 * s ** 2 * (1 - s) + s ** 3

    def ease(t):
        if t <= 0:
            return 0.0
        if t >= 1:
            return 1.0
        lo, hi = 0.0, 1.0
        for _ in range(32):
            mid = (lo + hi) / 2
            if bez(x1, x2, mid) < t:
                lo = mid
            else:
                hi = mid
        return bez(y1, y2, (lo + hi) / 2)
    return ease


EASE_OUT = cubic_bezier(0.23, 1, 0.32, 1)       # входы: подъём, карточки, строки заголовка
EASE_OUT_EXPO = cubic_bezier(0.16, 1, 0.3, 1)   # pop чипов и кнопок
EASE_IN_OUT = cubic_bezier(0.77, 0, 0.175, 1)   # шторки, переходы, дрейф
EASE_LINE = cubic_bezier(0.76, 0, 0.24, 1)      # линии, уход прелоадера


def linear_gradient(size, stops, angle_deg=104):
    """RGB-картинка, залитая как CSS linear-gradient(<angle>deg, stops)."""
    w, h = size
    a = math.radians(angle_deg)
    dx, dy = math.sin(a), -math.cos(a)            # CSS: 0deg = вверх, 90deg = вправо
    length = abs(w * dx) + abs(h * dy)
    yy, xx = np.mgrid[0:h, 0:w].astype(np.float32)
    p = ((xx - w / 2) * dx + (yy - h / 2) * dy) / length + 0.5
    pos = [s for s, _ in stops]
    cols = [hex_rgb(c) for _, c in stops]
    out = np.stack([np.interp(p, pos, [c[i] for c in cols]) for i in range(3)], axis=-1)
    return Image.fromarray(out.clip(0, 255).astype(np.uint8))


def mesh_background(theme="light", w=W, h=H):
    """Фоновая «дымка» сайта, адаптированная под 9:16."""
    if theme == "light":
        base = [(0, "#FBFCFF"), (0.30, "#F2F5FF"), (0.60, "#FAF7FF"), (1, "#EEF7FB")]
        spots = [(0.88, 0.06, 900, (107, 148, 255), 0.30, 0.70),
                 (0.04, 0.38, 820, (205, 136, 255), 0.22, 0.72),
                 (0.96, 0.70, 900, (67, 205, 236), 0.18, 0.72),
                 (0.10, 0.98, 820, (126, 108, 255), 0.18, 0.72)]
    else:
        base = [(0, "#0D1019"), (0.35, "#11152A"), (0.65, "#151224"), (1, "#0C171F")]
        spots = [(0.88, 0.06, 900, (82, 119, 222), 0.26, 0.70),
                 (0.04, 0.38, 820, (147, 79, 199), 0.20, 0.72),
                 (0.96, 0.70, 900, (37, 142, 172), 0.16, 0.72),
                 (0.10, 0.98, 820, (89, 70, 187), 0.18, 0.72)]
    yy, xx = np.mgrid[0:h, 0:w].astype(np.float32)
    t = yy / (h - 1)
    img = np.stack([np.interp(t, [p for p, _ in base], [hex_rgb(c)[i] for _, c in base]) for i in range(3)], axis=-1)
    for px, py, r, rgb, alpha, fade in reversed(spots):
        d = np.hypot(xx - px * w, yy - py * h) / r
        k = (np.clip(1 - d / fade, 0, 1) * alpha)[..., None]
        img = img * (1 - k) + np.array(rgb, np.float32) * k
    return Image.fromarray(img.clip(0, 255).astype(np.uint8))


def blob_points(cx, cy, r, t, angle=0.0, speed=0.0, n=42):
    """Контур «жидкой капли» (из useSectionLiquid.ts). t — секунды, speed 0..1, angle — направление движения."""
    pts = []
    for i in range(n):
        a = 2 * math.pi * i / n
        wobble = (math.sin(a * 3 + t * 2.2) * 0.095
                  + math.sin(a * 5 - t * 1.55) * 0.06
                  + math.sin(a * 7 + t * 0.84) * 0.036)
        pulse = math.cos((a - angle) * 2) * speed * 0.07
        tension = abs(math.sin(a - angle)) * speed * 0.04
        rr = r * (1 + wobble + pulse - tension)
        stretch = r * speed * math.cos(a - angle) * 0.085
        pts.append((cx + math.cos(a) * rr + math.cos(angle) * stretch,
                    cy + math.sin(a) * rr + math.sin(angle) * stretch))
    return pts


def smooth_closed(pts, steps=8):
    """Catmull-Rom по замкнутому контуру -> плотный полигон для ImageDraw.polygon."""
    out, n = [], len(pts)
    for i in range(n):
        p0, p1, p2, p3 = pts[i - 1], pts[i], pts[(i + 1) % n], pts[(i + 2) % n]
        for s in range(steps):
            u = s / steps
            out.append(tuple(0.5 * (2 * p1[k] + (p2[k] - p0[k]) * u
                                    + (2 * p0[k] - 5 * p1[k] + 4 * p2[k] - p3[k]) * u * u
                                    + (3 * p1[k] - p0[k] - 3 * p2[k] + p3[k]) * u ** 3) for k in range(2)))
    return out


def blob_mask(size, cx, cy, r, t, angle=0.0, speed=0.0, ss=4):
    """Сглаженная маска капли (L), суперсэмплинг ×ss."""
    w, h = size
    m = Image.new("L", (w * ss, h * ss), 0)
    pts = smooth_closed(blob_points(cx * ss, cy * ss, r * ss, t, angle, speed))
    ImageDraw.Draw(m).polygon(pts, fill=255)
    return m.resize((w, h), Image.LANCZOS)


def tracked_width(text, font, tracking=0.0):
    return sum(font.getlength(ch) for ch in text) + tracking * font.size * max(len(text) - 1, 0)


def draw_tracked(draw, xy, text, font, fill, tracking=0.0):
    """Текст с letter-spacing как в CSS (tracking в em: -0.035, 0.18 …). PIL сам трекинг не умеет."""
    x, y = xy
    for ch in text:
        draw.text((x, y), ch, font=font, fill=fill)
        x += font.getlength(ch) + tracking * font.size
    return x


def gradient_text(img, xy, text, font, tracking=0.0, stops=IRIDESCENT, angle_deg=104):
    """Переливающийся текст (как внутри капли): маска текста + CSS-градиент."""
    w = int(math.ceil(tracked_width(text, font, tracking))) + 2
    asc, desc = font.getmetrics()
    mask = Image.new("L", (w, asc + desc), 0)
    draw_tracked(ImageDraw.Draw(mask), (0, 0), text, font, 255, tracking)
    img.paste(linear_gradient((w, asc + desc), stops, angle_deg), xy, mask)
```
