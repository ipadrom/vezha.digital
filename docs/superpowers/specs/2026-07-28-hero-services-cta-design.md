# Hero services CTA

## Goal

Вторичная кнопка в hero должна вести к секции «Что мы делаем», а не к стеку.

## Design

- Якорь кнопки меняется с `#stack` на `#services`.
- Русская подпись: `Смотреть услуги`.
- Английская подпись: `View services`.
- Поле локализации и тип компонента переименовываются с `stackLink` на `servicesLink`.
- Внешний вид, стрелка и основная кнопка «Обсудить проект» не меняются.

## Verification

- В hero не остаётся ссылки `href="#stack"`.
- RU/EN используют новый ключ `servicesLink`.
- JSON локализаций и production-сборка Nuxt остаются валидными.
