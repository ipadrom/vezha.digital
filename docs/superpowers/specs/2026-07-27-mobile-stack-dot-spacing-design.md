# Mobile stack dot spacing

## Goal

На мобильных экранах увеличить вертикальное расстояние между точками списка «Стек», не увеличивая высоту секции.

## Design

- В мобильной временной шкале устанавливается вертикальный промежуток `12px` между четырьмя пунктами.
- Промежуток добавляется внутри существующего контейнера `.vz-stack__mobile-layout` с `min-height: 218px`.
- Высота секции, размер точек, размер активного ореола, положение правой плашки и десктопная временная шкала не меняются.
- Геометрия соединительной линии продолжает вычисляться по центрам первой и последней точки.

## Verification

- До правки мобильная временная шкала не имеет явного `row-gap: 12px`.
- После правки промежуток применяется только внутри мобильного media query.
- Существующая высота `.vz-stack__mobile-layout` остаётся `218px`.
- Production-сборка Nuxt должна завершаться успешно.
