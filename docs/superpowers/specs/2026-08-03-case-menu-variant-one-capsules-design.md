# Вариант 1: капсульный выбор кейса

## Цель

Развить первый вариант меню кейсов и убрать из селектора прямоугольные карточки, которые не совпадают с пластикой основного сайта.

## Решение

- На десктопе слева остаётся вертикальная редакторская навигация, но каждый кейс становится самостоятельной мягкой капсулой без рамки.
- Активная капсула имеет тёмную заливку, светлый текст и небольшой фиолетовый круглый маркер. Неактивные элементы используют спокойную серую подложку и усиливаются при наведении.
- Номер, название и тип проекта сохраняются. Название получает основной визуальный вес, служебные данные остаются моноширинными.
- Между капсулами есть воздух; общий контейнер не получает рамку и не выглядит таблицей.
- На мобильном капсулы превращаются в горизонтальную прокручиваемую строку. Активная капсула шире и показывает название; служебный тип скрывается.
- Нажатие на капсулу меняет активный проект и текст демонстрационного контента, чтобы селектор ощущался рабочим.

## Ограничения

- Меняется только вариант 1. Варианты 2–5 остаются без изменений.
- Существующая страница сравнения, переключатель «Десктоп / Мобилка» и URL-состояние сохраняются.
- Новые зависимости и растровые ассеты не добавляются.

## Проверка

- Автоматическая проверка подтверждает капсульный радиус, отсутствие табличных разделителей и наличие обработчика выбора.
- Производственная сборка должна завершаться успешно.
- Все пять вариантов в обоих режимах должны продолжать возвращать HTTP 200.
