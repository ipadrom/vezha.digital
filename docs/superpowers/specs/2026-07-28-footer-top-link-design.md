# Footer top link

## Goal

Упростить верх футера: удалить фразу «Всё по проекту. В одном месте. Спокойно.» и внутреннюю горизонтальную линию, а ссылку возврата наверх разместить над верхней границей футера.

## Design

- Поле `footer.tagline` удаляется из RU/EN локализаций и TypeScript-типов.
- В `.vz-footer__top` остаётся только ссылка `topLink`.
- `.vz-footer__top` выводится абсолютным правым элементом над `border-top` футера и не занимает высоту внутри футера.
- `border-bottom` старой строки удаляется.
- На мобильных экранах ссылка сохраняет положение над границей и получает правый отступ `20px`.
- Остальные колонки, крупная подпись VEZHA, legal-блок и игра не меняются.

## Verification

- В компоненте и локализациях нет `tagline`.
- `.vz-footer__top` не содержит `border-bottom`.
- Ссылка позиционируется над футером через `bottom: calc(100% + ...)`.
- RU/EN JSON и Nuxt production build остаются валидными.
