# Crew network graph

An anonymised 12-second Remotion composition for the ИП Загорулько case. It presents three crew leaders as anchor nodes, reveals numeric relationship weights on employee cards and highlights the strongest line-ups. The animation is a conceptual data visualisation, not a reproduction of the product interface.

```powershell
npm install
npm run dev
npm run lint
npm run render
npm run poster
```

Rendered files are written to `out/`. The public case uses copies in `frontend/public/cases/gbu-process-automation/`.

The 1600×900 composition is rendered at 2× scale (3200×1800), using lossless PNG intermediate frames and H.264 CRF 16. The JPEG poster uses the same output dimensions at quality 95.
