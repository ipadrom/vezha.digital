# Кейс SSAG

`case.json` — документ штатного конструктора кейсов (`CaseDocumentUpdate`), на русском и английском. Восемь блоков используют существующий конструктор и композицию кейса ГБУ. Для блока шагов с композицией `phone-showcase` («Список с телефоном» в админке) общий публичный рендерер показывает экран по центру левой колонки заголовков и компактный аккордеон в правой колонке текста. Экран меняется только по нажатию на пункт; карта и карточка места переключаются внутри одного блока. Высота аккордеона резервируется под самое длинное описание и пересчитывается при изменении ширины или текста. На мобильных сохраняются две колонки: телефон слева и аккордеон справа. Узкая компоновка использует уменьшенные отступы, заголовки без номеров на телефонах и краткую подпись экрана; скриншот открывается в полном размере по нажатию. Техническая подпись об эмуляторе удалена из текущего текста секции. Дополнительных таблиц и отдельного механизма публикации нет; сохранённые документы и снимок миграции остаются совместимыми.

Локальная страница: http://localhost:3000/cases/ssag/

Изображения: `frontend/public/cases/ssag/`. В `screens/` находятся исходные PNG 1440 × 3200, снятые напрямую из эмулятора SSAG. `ssag-cover-map-sos-button.png` — обложка галереи со светлой картой, контурным глобусом и подписью «Карта помощи и SOS-кнопка». `ssag-devices.png` — парный мокап внутри кейса; `ssag-received-message.png` — постановочное изображение SMS у получателя. Обложка и мокапы созданы встроенным imagegen с исходными экранами в качестве референсов; они не являются побитовой вставкой скриншотов. Полосы системных жестов на парном мокапе удалены по запросу.

Контакты вымышлены, код номера `000` недопустим. Координаты в фото сообщения — пример центра города, а не местоположение пользователя. Реальные SMS при подготовке не отправлялись. В тексте отражён статус прототипа без обещаний подтверждённой доставки.

Документ доступен в локальном конструкторе, id `c1bec48e-e9c1-45c1-9877-fde4e4abdbcf`.

Первичная доставка на production выполняется штатным CI/CD: миграция `d0s1t2u3v4w5` использует зафиксированный документ `backend/alembic/data/ssag_case_20260907.json`, добавляет SSAG, его блоки и первую опубликованную версию. Существующий кейс с тем же slug не перезаписывается. Откат миграции не удаляет контент. После выпуска изменения опубликованного кейса вносятся через штатный конструктор; снимок миграции остаётся неизменным.
